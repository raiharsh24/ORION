# Project Roadmap

This roadmap outlines the goals and planned features for upcoming versions of the FRIDAY AI system.

---

## [v1.5.1] - Maintenance & FACS Expansion
- Verify automated event-driven document updates in the background.
- Integrate FACS notifications into the Electron HUD overlay interface.
- Complete coverage of workspace document indexers and retrieval engines.

---

## [v1.6.0] - HUD Command Center
- Full desktop control integration for HUD display widgets.
- Context Ranker optimizations using dual-encoder retrieval models.
- Support for custom tools registries and dynamic tool enablement inside the UI.

---

## [v1.7.0] - Voice & Multi-Agent Orchestration
- Integration of audio TTS/STT pipelines directly with the workspace manager.
- Advanced cognitive orchestrator supporting multiple concurrent sub-agents.
- Collaborative task distribution protocols between specialized agents.

---

## [v2.0.0] - Fully Autonomous Lifecycle
- Next-generation self-improving autonomous loop utilizing live reinforcement learning feedback.
- Persistent knowledge base updates via local semantic learning consolidation.
